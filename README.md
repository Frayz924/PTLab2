# Лабораторная 2 по дисциплине "Технологии программирования"

## Постановка задачи

**Вариант 5. Магазин алкогольной продукции.**

Требуется доработать учебный проект интернет-магазина (Django + PostgreSQL), добавив функциональность корзины:

- покупатель может добавлять товары в корзину;
- корзина может содержать **несколько экземпляров одного товара**;
- пользователю показывается **общее количество** товаров в корзине.

## Краткое описание проекта

Учебный интернет-магазин, реализованный по модели MVC на фреймворке Django. Основные сущности:

- `Product` — товар (название, цена);
- `Purchase` — оформленная покупка (товар, покупатель, адрес, дата);
- `CartItem` — позиция корзины (товар, количество, привязка к сессии).

Корзина реализована **на сессиях** (без обязательной авторизации): каждая позиция привязана к `session_key`. Если товар уже есть в корзине, при повторном добавлении увеличивается его количество. На странице корзины отображается таблица позиций и общее количество товаров.

## Используемые технологии

- **Python 3.8**
- **Django 4.2** — веб-фреймворк (MVC)
- **PostgreSQL 18** — база данных
- **psycopg2-binary 2.9.6** — драйвер PostgreSQL
- **PyYAML** — загрузка фикстур
- **dj-database-url 2.2.0**, **django-heroku**, **whitenoise** — вспомогательные пакеты
